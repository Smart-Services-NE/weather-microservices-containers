# Specification: Implement Freezing Alert System\n\n## Overview\nThis track implements a freezing alert system that notifies users when the temperature drops below freezing (0°C). It involves detecting freezing temperatures via the `WeatherService` and publishing alerts to a Kafka topic.\n\n## Requirements\n- **Freezing Detection:** Correctly determine if a temperature is freezing (`celsius <= 0`).\n- **Alert Publication:** Publish freezing alert messages to the `weather-alerts` Kafka topic using the Avro schema defined in `schemas/avro/weather-alert.avsc`.\n- **Orchestration:** Coordinate location lookup, weather data fetching, and alert publication within the `WeatherManager`.\n- **API Integration:** Provide a POST endpoint `/api/weather/alerts/freezing` that accepts a zip code and email address.\n\n## Architectural Mapping\n- **Contracts:** Define `WeatherAlertDto` and `IWeatherAlertEngine`.\n- **Engines:** Implement `WeatherAlertEngine` with `IsFreezing` logic.\n- **Accessors:** Implement `AlertPublisherAccessor` for Kafka messaging.\n- **Managers:** Update `WeatherManager` to orchestrate the alert flow.\n- **Clients:** Add the API endpoint in the controller.
